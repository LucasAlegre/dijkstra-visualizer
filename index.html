Pseudocódigo

procedure DijkstraHeap(G = (V, E), s, ℓ)

  1. Entrada: grafo G = (V, E) em listas de adjacência, um vértice s ∈ V e pesos ℓe ≥ 0 para cada e ∈ E
  2. Pós-condição: para todo vértice v, dist(v) é a distância d(s, v)
  3. X ← ∅, H ← heap vazio
  4. key(s) ← 0
  5. for cada v ≠ s do
  6. key(v) ← +∞
  7. Heapify(V)
  8. while H não está vazio do
  9. w* ← ExtractMin(H)
  10. Adicione w* a X
  11. dist(w*) ← key(w*)
  12. for cada aresta (w*, y) com y ∉ X do
  13. Delete y de H
  14. key(y) ← min{key(y), dist(w*) + ℓw*y}
  15. Insira y em H
  16. Retorne dist
