Pseudocódigo

procedure DijkstraHeap(G = (V, E), s, ℓ)

  1. Entrada: grafo dirigido G = (V, E) em listas de adjacência, um vértice s ∈ V e pesos ℓe ≥ 0 para cada e ∈ E
  2. Pós-condição: para todo vértice v, dist(v) é a distância d(s, v)
  3. X ← ∅
  4. dist(v) ← +∞ para todo v ∈ V
  5. dist(s) ← 0
  6. H ← heap contendo apenas o par (0, s)
  7. while H não está vazio do
  8. (d, u) ← ExtractMin(H)
  9. if u ∈ X then
  10. continue ▷ par obsoleto: u já foi processado
  11. Adicione u a X ▷ d = dist(u)
  12. for cada aresta (u, v) ∈ E do
  13. if d + ℓuv < dist(v) then
  14. dist(v) ← d + ℓuv
  15. Insert(H, (dist(v), v))
  16. Retorne dist

Como usar

  • Avançar / Voltar executa o algoritmo um passo por vez (teclas → / ← ou espaço).
  • Automático avança sozinho (tecla A); Reiniciar volta ao início (Home).
  • Pseudocódigo mostra a linha executada em cada passo (tecla P).
  • Grafos carrega um exemplo ou gera um grafo aleatório.
  • A fila H guarda pares (dist, v) e começa só com (0, s). Pares cinza são obsoletos: o vértice já está em X ou há um par mais novo, com distância menor. Quando um par obsoleto sai da fila, ele é descartado.
  • No passo inicial, clique em um vértice para escolhê-lo como origem s.
  • Passe o mouse sobre um vértice ou uma linha da tabela para ver o caminho até ele.
