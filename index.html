How to use this tool

Run step: Advance the algorithm by one step.

Auto run: Run the algorithm automatically at a fixed speed.

Reset: Reset the current graph to the initial state.

New Random Graph: Generate a random graph using the selected node count and density.

In the graph view, the blue node is the start node. The orange node is the current node being evaluated. The teal nodes have been visited and their shortest path is known.
